# my-website
📝 毎日メモ

毎日使いたくなるメモ帳。

メモ・予定・デイリーミッションをひとつの画面にまとめた Web アプリです。 連続記録やポイント、称号で、「今日も開こう」と思えるメモ帳を目指しています。

毎日メモ

✨ 主な機能
🔥 連続記録
アプリを開いた日数を毎日カウントします
続けた日数に応じて、応援メッセージと称号が変わります（🌱 希望の芽 → ✨ 不撓不屈）
🎯 今日のミッション
毎日、候補の中から最大3つのミッションを選びます（「おまかせ」も選べます）
最初から入っているミッションは、操作するとアプリが判定して自動で達成になります
例：メモを保存すると「メモを1個追加する」を達成
自分で追加したミッションは、「達成する」ボタンで手動でチェックします
例：「腕立て10回」「本を10ページ読む」など
達成するとポイントがもらえます。全部達成すると +20pt のボーナス
💎 ポイント称号
貯めたポイントに応じて称号が上がります（🌱 記録のはじまり → ✨ 思い出の宝箱）
📝 メモ
メモの追加・編集・削除ができます
📅 カレンダー・予定
月ごとのカレンダーに予定を表示します
日付をタップすると、その日の予定を追加・削除できます
「近い予定」に直近5件をカウントダウン付きで表示します（今日・明日・3日以内は色分け）
今日と明日の予定をブラウザの通知でお知らせします（設定メニューからオンにします）
🎨 カスタマイズ
テーマカラーを6色から選べるほか、好きな色も自由に選べます
ダークモードに対応しています（最初は端末の設定に合わせます）
文字が読みにくい色を選んだときは、文字色を自動で調整します
🚀 使い方
ファイル一式を同じフォルダに置きます
index.html をブラウザで開きます

インストールやサーバーは必要ありません。

💡 予定の通知を使う場合は、file:// で開くよりも、Web サーバー経由（GitHub Pages など）で開くほうが確実に動作します。

💾 データの保存について

データはすべて、ブラウザの localStorage に保存されます。

サーバーには送信されません。自分の端末の中だけに保存されます
ブラウザのデータを消去すると、メモや記録もすべて消えます
別の端末や別のブラウザとはデータが共有されません
保存キー	内容
memos	メモ
events	予定
streak / lastLogin	連続記録
totalPoints	合計ポイント
dailyMissions / dailyMissionDate / dailyMissionTarget	今日のミッション
customMissions	自分で追加したミッション
deletedDefaultMissionIds	削除した初期ミッション
bonusAwardedDate	全達成ボーナスを受け取った日
themeColor / darkMode	見た目の設定
notifiedDate	予定を通知した日
